What makes a candidate submission-ready?

  • One-band float32 GeoTIFF, EPSG:32611, 100 m, exactly matching the competition grid's CRS, shape, bounds, and geotransform.
  • Finite prediction values inside the footprint, all within [0, 1]; outside-footprint cells null/NaN as the official specification allows.
  • Written file reopened and checked against the official sample; file hash recorded.
  • Spatially blocked holdout reported with evaluator version, withheld-positive count, and 95% CI; individual-feature leakage checks; registry similarity/overlap audit.
  • Unique submission name and short note. Promotion is a separate decision; no slot is spent on an unvalidated idea.

The current repository has not passed these checks. The items above describe gates, not completed validations.

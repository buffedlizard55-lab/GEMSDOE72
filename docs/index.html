Why a baseline, not a high score. The public leaderboard leader is ~0.326 (GEMSDOE32 read, 2026-10-04; the brief also cites 0.3195 / 0.3774 / 0.4413 at later reads). Beating it requires a detector trained on the competition features and validated on a spatially-blocked holdout. That training data is login-walled and unreachable here, so this repository ships the complete, verified pipeline (metric + writer + validator + tests) plus this format-valid baseline, ready to become competitive once data is placed in data/.

The one-minute version

  1. Download the submission GeoTIFF from the home page: GEMSDOE72-h71-walkerlane+geothermal-20261020T194646Z-0172d3a9-candidate.tif.
  2. Sign in to DrivenData, open the GEMS Prize Challenge (#306) submission page, click Make new submission.
  3. Upload the .tif (a .zip containing the single GeoTIFF is also accepted).
  4. Paste this note into Note (optional) (140 chars):
GEMSDOE72 H71 WALKERLANE+GEOTHERMAL | Walker Lane structural-grain dots + geothermal-field clusters; 8477 dots, off-catalogue by construction; format-valid candidate, organizer score pending

Submission name to use: GEMSDOE72-H71-WALKERLANE+GEOTHERMAL.

Submission format rules (official)

  • Single-band GeoTIFF (.tif), or a .zip containing a single GeoTIFF.
  • CRS: projected UTM zone 11N (EPSG:32611) — same as the training data.
  • Resolution: 100 m; same bounds as the training data; null/nan outside bounds allowed.
  • Datatype: 32-bit float (float32), values between 0 and 1 (probability/confidence of fault presence).
  • This repo's file: EPSG:32611, 100 m, 3730 × 3292, transform [100, 0, 243350, 0, -100, 4508550], float32, all finite, values in [0, 1], no nodata tag — audit.json.

Source: DrivenData problem description, "Submission format" — drivendata.org/competitions/306/competition-doe-gems/page/967/

⚠ The "Predicted values must be in range [0, 1]" error
  • DrivenData rejects any submission whose raster values fall outside [0, 1].
  • The same message is triggered by the float32 nodata sentinel -3.4028234663852886e+38 (used inside training_features.tif) if it is written through unchanged — 3,061 cells inside the submission footprint in that file.
  • This repo's file has no nodata tag and is all-finite — neither failure mode applies.

What this file is — and is not

  • It is a format-validated candidate submission (all format checks pass; sha256 pinned).
  • It is not organizer-scored: labels.tif is login-walled on DrivenData, so holdout DTI cannot be measured here and no organizer score exists.
  • It is not a copy of any previous GEMSDOE submission: the lane is Walker Lane structural-grain dotted segments plus geothermal-field clusters (Dixie Valley, Soda Lake, Steamboat, Brady's, Desert Peak), built without the catalogue — zero catalogue leakage by construction.

Before spending a weekly DrivenData submission slot, place the competition data in data/ (see scripts/download_competition_data.sh), run python scripts/prepare_data.py, re-test on the spatially-blocked holdout with scripts/evaluate_holdout.py, and regrid this TIF against the official sample_submission.tif if the grids differ.
